AST-02 // CONTEXT DEGRADATION ARTIFACT · a mesma entrada, os mesmos vetores. o que muda é a contenção.

O Native-SDD é um sistema de contenção.

Cada fase só existe porque a anterior deixou um artefato em disco. Nenhuma delas depende de alguém lembrar de pedir. A memória em .claude/ troca a lembrança do operador pela persistência do sistema, e o caminho da intenção ambígua ao artefato verificado não tem etapa opcional.

COMO COMEÇAR
  1. 1

    Instale

    Prepara a máquina: as ferramentas de linha de comando, o Claude Code e a sua configuração pessoal. Leva alguns minutos.

    $ pwsh -NoProfile -Command "irm https://raw.githubusercontent.com/Phenrique-DataDev/Native-sdd/main/onboarding/bootstrap.ps1 | iex"

    Rode num PowerShell 7 (pwsh).

    $ curl -fsSL https://raw.githubusercontent.com/Phenrique-DataDev/Native-sdd/main/onboarding/bootstrap.sh | bash

    Precisa de bash, curl e tar. No macOS, pede a senha de administrador uma vez.

    No fim, feche e abra um terminal novo.

  2. 2

    Crie o projeto

    Troque meu-projeto pelo nome que quiser. A pasta nasce com o método pronto e abre no VS Code.

    $ nsp meu-projeto -Open
  3. 3

    Comece no Claude Code

    Dentro do projeto, /setup registra a stack, o domínio e as convenções, e /init especializa os agentes para eles.

    › /setup
    › /init
